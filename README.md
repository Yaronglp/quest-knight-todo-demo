# ⚔️ BMAD Method v4 - Gamified Todo Demo

Built purely for demonstration purposes, this project showcases the power of the BMAD Method, utilizing agents as multiple copilots to assist developers in building applications and features.

This project is a gamified task management application that transforms your to-do list into an epic adventure. Complete tasks to battle dragons, gain experience, and level up your knight!


## 🎮 Features

- **Task Management** - Create urgent and normal tasks with descriptions
- **Dungeon Crawler Gameplay** - Your tasks spawn enemies to defeat
- **XP & Leveling System** - Gain experience and level up as you complete tasks
- **Animated Battles** - Watch your knight battle enemies with smooth animations
- **Persistent Progress** - All your data is saved locally in your browser
- **Desktop-Optimized UI** - Rich, engaging interface designed for desktop browsers


## 🛠️ Tech Stack

- **React 19.1.0** - UI framework with concurrent rendering
- **TypeScript 5.8.3** - Type-safe development
- **Vite 6.3.5** - Fast build tool and dev server
- **Tailwind CSS 3.4.0** - Utility-first styling
- **Zustand 4.4.0** - Lightweight state management
- **Framer Motion 11.15.0** - Animation library
- **ESLint + Prettier** - Code quality and formatting

## 🎮 How to Play

1. **Create Tasks** - Add tasks using the form. Mark urgent tasks to spawn dragons!
2. **Complete Tasks** - Check off tasks to trigger epic battle animations
3. **Gain XP** - Watch your experience bar fill and level up your knight
4. **Track Progress** - Your level and completed tasks persist across sessions
